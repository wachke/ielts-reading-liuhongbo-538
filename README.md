# ielts-reading-liuhongbo-538
# 雅思阅读 538 考点同义替换词记忆神器 📚 
> 基于刘洪波《剑桥雅思阅读考点词真经 538》整理，涵盖全书三大类 376 组（共 538 词）高频考点词及常用替换词，支持手机与电脑端离线背诵、真人英音朗读与真题仿真刷题。

---

### 📖 词库结构

* **第 1 类：超高频考点词（#1 ～ #20）**：涵盖指代、并列、因果、对比等剑桥真题核心逻辑高频词（90% 真题出题点）。
* **第 2 类：重点高频词（#21 ～ #120）**：雅思阅读高频转述与细节匹配核心词汇（60% 真题覆盖率）。
* **第 3 类：常考考点词（#121 ～ #376）**：按字母 A–W 排序的真题经典替换词全景汇总。

---

### ✨ 核心功能

* 📇 **智能抽认卡 (Flashcards)**：双面翻转卡片，展示考点排行、词性释义及所有真题替换词；支持「已掌握 / 模糊 / 不认识」艾宾浩斯记忆反馈与键盘快捷键。
* 🔊 **真人在线英音发音**：集成国内高速发音引擎（标准英式发音），无须开启代理/VPN，秒级清晰发音。
* 📑 **同义替换速查词表 (Table)**：三列标准排版（原词、词义、替换词及中文翻译），支持毫秒级中英文实时检索与生词本星标收藏。
* 📝 **真题同义替换速测 (Quiz)**：阅读仿真四选一测试，即时反馈正误，答错自动收录至专属错题本。
* 🎮 **消消乐连连看 (Match Game)**：考点原词与同义替换词卡片配对消除，强化瞬间反应速度。
* 📊 **离线进度持久化**：学习数据、已掌握状态及错题本自动保存在浏览器本地（LocalStorage），随时随地离线打卡。
